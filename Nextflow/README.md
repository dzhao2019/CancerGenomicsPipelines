# 🧬 Nextflow Mastery: 28-Day Course (Master Index)

Start here. Every day has its own folder with a **README.md** that links to all of that day's files. Work through the numbered files in order.

## How each day folder is organized

| File | What it is | Time |
|---|---|---|
| `README.md` | Day overview with links to every file, objectives and checklist | 2 min |
| `DayNN_1_Lesson.md` | **Main lesson — start here** | 30 min |
| `DayNN_2_InClass_Exercises.md` | Guided exercises (recognition → modification → creation), solutions collapsed | ~25 min |
| `DayNN_3_Homework.md` | Self-paced homework with solutions and reflection questions | ~45 min |
| `DayNN_4_Quick_Reference.md` | One-page cheat sheet | — |
| `DayNN_5_Extended_Lesson.md` | Days 1–14, 16, 17: longer all-in-one version of the lesson with extra examples | optional |
| `DayNN_extra_*.md` | Days 1, 17, 21: supplementary material | optional |

Course-wide documents are in **`00_Course_Guide/`**: `Course_Outline.md` (full curriculum), `Progress_Log.md` (fill in daily), `Course_Introduction.md`, and `Understanding_Nextflow.docx`.

## Daily routine

1. Open the day's `README.md`
2. Read `_1_Lesson` (30 min)
3. Do the in-class exercises, then the homework
4. Keep the quick reference open while coding
5. Log the day in `00_Course_Guide/Progress_Log.md`

## The running projects

- **Week 1** builds a multi-sample QC pipeline (Day 7)
- **Week 2** turns it into a robust, containerised QC → align → variant-calling pipeline (Day 14)
- **Week 3** refactors it into `minivar`: modular, nf-core modules, configurable and shareable (Day 21)
- **Week 4** builds `rnaseq-mini` from scratch across Days 22–24, then tests (25), scales (26) and monitors (27) it; Day 28 is your portfolio
